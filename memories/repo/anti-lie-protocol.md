- **EVERY gameplay claim MUST cite specific screenshot numbers**

Before any gameplay report:
1. **Count screenshots** - verify actual number captured
2. **Examine EACH screenshot** - document visible counters
3. **Cross-reference claims** - every claim must match screenshot evidence
4. **Document discrepancies** - if claim doesn't match, STOP and correct

### 3. MANDATORY HONESTY STAMPS
Every gameplay report MUST include:
- checkmark VERIFIED: Screenshots #X-Y examined
- checkmark ENEMIES SPAWNED: [exact count from screenshots]
- checkmark KILLS ACHIEVED: [exact count from screenshots]
- checkmark SCORE GAINED: [exact score from screenshots]
- X UNABLE TO VERIFY: [specific reason] - if verification fails

### 4. FORBIDDEN CLAIMS (AUTOMATIC LIE DETECTION)
These phrases trigger immediate challenge:
- 'killed enemies' without screenshot citation
- 'combat worked' without specific numbers
- 'testing successful' without verification stamps
- 'enemies engaged' without enemy count proof
- Any claim about gameplay without screenshot evidence
