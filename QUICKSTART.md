# 🚀 Quick Start - Old Eden

## Windows Users

**Just double-click `start.bat`** - that's it!

The launcher will automatically:
- ✅ Check for Node.js (and tell you if you need to install it)
- ✅ Install all dependencies (first run only)
- ✅ Set up configuration
- ✅ Start the game server

The game will be available at `http://localhost:3000`

---

## Linux/Mac Users

**Run `./start.sh`** in your terminal:

```bash
chmod +x start.sh  # First time only
./start.sh
```

---

## Requirements

- **Node.js 20.0.0+** - Download from [nodejs.org](https://nodejs.org/) if you don't have it

---

## Staging/Online Testing

For deploying to a staging environment for online testing:

1. Go to your repository `Settings` → `Pages`
2. Under "Source", select `GitHub Actions`
3. Push to `staging` or `develop` branch
4. Your staging site will be live at: `https://[username].github.io/oldeden/`

**Or manually trigger:** Go to `Actions` tab → `Deploy Staging Environment` → `Run workflow`
